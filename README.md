## Wind Tunnel Requirements:

Stable laminar flow wind which is needed since we want good, clear and true results. Stable laminar flow wind will result in a stable wind that has a similar velocity everywhere. This can be achieved through a kind of sift that creates resistance for the wind so that it is spread out more evenly, the best shape for the holes of the sift are hexagons because of their unrivaled unwasted space usage. With this laminar flow things like flow turbelence are less likely to occur and in turn will result in more precise results.

Enclosed space, An enclosed space is needed since we want to accurately simulate the conditions of high air speeds, and to achieve these precise simulations we need a good enviroment without disturbances, this is easily achieved by enclosing the space, therefore the name "tunnel.

Wind draft, a wind draft is required since we want to simulate the aerodynamics of for example a wing in the air at certain speeds. This can be achieved by either "pushing" or "puling" air through the enclosed space, this can be achieved by simply installing a fan with a sufficient rpm to either pull or push the air but pulling is considered superior since it greatly simplifies the process of building the wind tunnel.

A Smoke generator, to try and visualize how the wind contorts and deforms when interactting with a foreign object we want to be able to visualize it, this can be achieved using smoke. The easiest way to get a smoke generator is to use a cheap E-ciggarete, although it may be harmful.
